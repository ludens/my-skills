# Twemoji

twemoji SVG 이모지를 찾고, 내려받고, SVG 다이어그램에 삽입할 때 참조하는 가이드.

## 소스

| 항목 | 값 |
| --- | --- |
| 원본 | <https://github.com/twitter/twemoji> — 관리 중단(2022-01 v14.0.2 이후 중단) |
| 포크(실제 소스) | <https://github.com/jdecked/twemoji> — Mastodon·Misskey 등이 쓰는 유지보수 포크 |
| 버전 | v17.0.3 고정 |
| CDN | `https://cdn.jsdelivr.net/gh/jdecked/twemoji@17.0.3/assets/svg/<codepoint>.svg` |
| raw 대체 | `https://raw.githubusercontent.com/jdecked/twemoji/v17.0.3/assets/svg/<codepoint>.svg` |
| 스크립트 캐시 | `~/.cache/twemoji/17.0.3/`(`TWEMOJI_CACHE_DIR`로 변경 가능) |

버전을 `master`나 풀어 쓰지 않는다. 최신 이모지(🫩 `1fae9` 등)는 구버전(예: 15.1.0)에는 없어 404가 난다.

## 파일명 규칙

이름은 코드포인트(소문자 hex, 선행 0 없음)를 `-`로 연결한 값이다. 스크립트가 변환하지만, 직접 URL을 만들 때 필요하다.

| 이모지 | 코드포인트 | 비고 |
| --- | --- | --- |
| 👍 | `1f44d` | 기본 |
| ❤️ | `2764` | U+FE0F 제거. `2764-fe0f.svg`는 404 |
| ©️ | `a9` | U+FE0F를 벗기면 있는 폴백. 원본 `a9-fe0f`도 404 |
| 🇰🇷 | `1f1f0-1f1f7` | 국기: regional indicator 2개 연결 |
| 🧑‍💻 | `1f9d1-200d-1f4bb` | ZWJ(U+200D)를 그대로 `-`로 연결 |
| 👍🏽 | `1f44d-1f3fd` | 피부 톤 modifier를 버리지 않는다 |
| 🫩 | `1fae9` | v17.0.3에 존재(구버전이면 404) |

- U+FE0F(이모지 프레젠테이션 선택자)는 파일명에서 제거하는 게 기본이고, 제거했을 때 404면 원본(fe0f 포함) 이름으로 재시도한다. 스크립트가 이 순서를 처리한다.
- ZWJ(`200d`)와 피부 톤(`1f3fb`–`1f3ff`)은 파일명의 일부다. 빼면 404다.
- 모든 SVG는 `viewBox="0 0 36 36"`이고 크기 변형은 없다.

## 빠른 선택

카탈로그를 외울 필요가 없다. 의도에 맞는 이모지만 결정하면 파일명이 따라온다. 국가는 해당 국기 이모지로 바꿔 쓴다.

| 다이어그램 용도 | 이모지 | 코드포인트 |
| --- | --- | --- |
| 인터넷·네트워크 | 🌐 | `1f310` |
| 사용자(익명·일반) | 👤 | `1f464` |
| 개발자·편집 역할 | 🧑‍💻 | `1f9d1-200d-1f4bb` |
| 성공·통과 | ✅ | `2705` |
| 실패·오류 | ❌ | `274c` |
| 경고·주의 | ⚠️ | `26a0` |
| 지역·국가 | 🇰🇷 | `1f1f0-1f1f7` |
| 권한·관리자 | 👑 | `1f451` |
| 좋아요·승인 | 👍 | `1f44d`(피부 톤은 뒤에 붙인다: `1f44d-1f3fd`) |
| 알림 | 🔔 | `1f514` |
| 메시지·댓글 | 💬 | `1f4ac` |
| 검색 | 🔍 | `1f50d` |

## 다운로드

```bash
# 하나
bash scripts/fetch-emoji.sh assets/twemoji 🇰🇷

# 여러 개
bash scripts/fetch-emoji.sh assets/twemoji 🇰🇷 ❤️ 🧑‍💻

# 파일명 확인
bash scripts/fetch-emoji.sh assets/twemoji --list 1f1f0-1f1f7

# 캐시 위치를 바꿔서
TWEMOJI_CACHE_DIR=/tmp/twemoji-cache bash scripts/fetch-emoji.sh assets/twemoji 👍
```

`fetch-emoji.sh`는 받은 SVG를 캐시 디렉터리에 저장한 뒤 `OUTPUT_DIR`로 복사한다. 일부가 404여도 성공한 것은 저장하고 진행하며, 실패 이모지는 이모지별로 시도한 파일명을 출력하고 마지막에 exit 1로 끝난다.

삽입 규칙:

1. 바깥 `<svg>`의 `viewBox="0 0 36 36"`을 `<symbol viewBox="...">`로 옮긴다. twemoji는 전부 이 값이다.
2. 원본의 모든 `id="..."` 속성은 제거한다. `fill="url(#...)"`로 실제 참조되는 `gradient`·`clipPath` id만 남겨 `tw-<이름>__` 접두사로 네임스페이스한다. 여러 심볼을 인라인하면 id가 충돌하므로 접두사가 필요하다(위 세 이모지는 참조가 없어 해당 없음).
3. `fill`은 파일에 이미 있다(대부분 단색 path). 재색칠하지 않는다. 색을 바꿔야 하는 디자인이면 다른 이모지를 고른다.
4. `<use>`에 `width`/`height`를 주고 24–48px 슬롯에 맞춘다.

## 배치

- 다이어그램 안에서 이모지 크기를 통일한다(24–48px). twemoji는 모두 `0 0 36 36`이라 같은 크기로 놓으면 밀도가 균일하다.
- 이모지 옆에 라벨을 함께 적는다. 👤만으로는 일반 사용자인지 관리자인지 구분이 안 된다.
- ✅·❌는 상태 표시(테이블/시퀀스 판정)에, 🌐·👤은 노드 표시에 쓴다. 역할을 섞지 않는다.
- 어두운 배경에서도 그대로 렌더된다. twemoji엔 다크 변형이 없고 역광 문제는 크지 않으므로 신경 쓰지 않는다.

## 자주 틀리는 것

| 오해·증상 | 실제 |
| --- | --- |
| unpinned URL을 쓴다(`master`, `@latest`) | 버전을 고정한다. CDN `@17.0.3`, raw `/v17.0.3/`. 없는 파일이 갑자기 404로 변하거나 이전 다이어그램 재현이 깨진다. |
| 오래된 버전(15.1.0)을 쓴다 | 파일은 있지만 최신 이모지(🫩 `1fae9`)가 없어 404다. |
| ❤️를 `2764-fe0f.svg`로 쓴다 | `2764.svg`가 정답. `2764-fe0f.svg`는 404다. |
| 대문자·선행 0으로 쓴다(`1F44D`, `01f44d`) | 소문자, 선행 0 없음. `1f44d`다. |
| ZWJ를 빼먹는다(`1f9d1-1f4bb`) | `1f9d1-200d-1f4bb`다. `200d`가 없으면 404. |
| 피부 톤을 버린다 | `1f44d-1f3fd`의 `1f3fd`는 파일명의 일부다. |
| 가져온 이모지를 재색칠한다 | 색이 path `fill`에 박혀 있다. 그대로 둔다. |
| 인라인한 원본 `id`를 남긴다 | 여러 이모지에서 충돌한다. 제거하거나 접두사로 네임스페이스한다. |
| viewBox를 추측해 적는다 | 항상 `0 0 36 36`이다. |

## 검증

```bash
# 코드포인트 → 파일명 확인
bash scripts/fetch-emoji.sh assets/twemoji --list 1f1f0-1f1f7

# 내려받은 SVG가 유효한지
xmllint --noout assets/twemoji/*.svg

# 결과 다이어그램 XML 검증
xmllint --noout diagram.svg
```

브라우저나 `qlmanage -p`로 실제 렌더링을 확인한다. ImageMagick의 내장 SVG 렌더러는 일부 path를 처리하지 못하므로 판정 기준으로 쓰지 않는다.
