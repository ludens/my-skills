# tistory-skin

티스토리 스킨(`skin.html`, `index.xml`, `style.css`)을 만들거나 수정할 때 쓰는 스킬입니다.

작업 절차는 [`SKILL.md`](SKILL.md)를 따릅니다. 치환자 정의와 예제는 [`references/`](references/)만 봅니다.

## 출처

`references/`의 치환자 문서는 티스토리 공식 스킨 가이드를 옮긴 것입니다.

- 문서: [티스토리 스킨 가이드](https://tistory.github.io/document-tistory-skin/)
- 저장소: [tistory/document-tistory-skin](https://github.com/tistory/document-tistory-skin)
