## 선택 메모

- `api`는 API 제품, `api-shield`는 API Shield다.
- `pages`는 Pages 서비스, `pages-logo`는 Pages 로고다.
- `workers`는 Workers, `workers-ai`는 Workers AI다.
- `warp-client`는 WARP Client, `WarpConnector`는 WARP Connector다.
- Zero Trust 아키텍처의 브랜드 표기는 `ZeroTrustLogo` 또는 `cloudflare-one`을 쓴다.
- `Cloudflared`, `ZeroTrustLogo`, `Onetimepin`, `WarpConnector`, 디바이스/로고 slug는 대소문자를 구분한다.
- `logo-inline`과 `ZeroTrustLogo`는 가로로 긴 로고다. 서비스 노드가 아니라 브랜드/제목 영역에 배치한다.
